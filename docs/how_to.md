\# NPM/Node.js Build Protocol



npm/Node.js projects have their own build system conventions. 



\## The npm "Build System"



\*\*`package.json`\*\* = Your CMakeLists.txt

\*\*`tsconfig.json`\*\* = Your compiler flags  

\*\*`npm run compile`\*\* = Your `make` command



\## What Goes in Source Control



\*\*✅ CHECK IN:\*\*

\- `package.json` (build configuration)

\- `tsconfig.json` (compiler settings)

\- `src/` folder (your source code)

\- `media/` folder (static assets)

\- `.vscode/launch.json` and `.vscode/tasks.json` (debug config)



\*\*❌ DON'T CHECK IN:\*\*

\- `out/` folder (compiled JavaScript - like your `build/` folder)

\- `node\_modules/` folder (dependencies - like `/usr/lib`)

\- `\*.vsix` files (packaged extension - like your executable)



\## Quick Check of Your Directory



Run this to see what you have:

```bash

ls -la

```



You should commit everything EXCEPT:

\- `out/` (generated by `npm run compile`)

\- `node\_modules/` (generated by `npm install`)



\## Create a .gitignore



Save the `.gitignore` file I created above to your project root. This tells git to ignore generated files.



\## The "CMakeLists.txt" Equivalent



Your `package.json` \*\*scripts section\*\* is like CMake targets:

```json

"scripts": {

&nbsp; "compile": "tsc -p ./",     // Like: make all

&nbsp; "watch": "tsc -watch -p ./", // Like: make watch  

&nbsp; "clean": "rm -rf out/\*"     // Like: make clean

}

```



\## Clean Development Workflow



```bash

\# Someone clones your repo (only source files)

git clone your-repo

cd your-extension



\# Install dependencies (like: sudo apt install build-essential)

npm install



\# Build (like: make)

npm run compile



\# Ready to develop!

```



The key difference from C++: npm downloads ALL dependencies locally to `node\_modules/` (like having `/usr/lib` inside each project), whereas C++ typically uses system-wide libraries.



Think of `node\_modules/` as a local copy of all your linked libraries that you never commit to source control - just like you don't commit your `build/` folder!
